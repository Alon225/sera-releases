# SERA Management releases

Installers and automatic-update packages for SERA Management (Windows desktop + NinjaTrader 8 Bridge).
Each release carries `SERASetup.exe`, `GuardianBridgeSetup.exe` (+ `.sha256`), the Velopack update feed
and `CHECKSUMS.sha256`. Install steps are in the `SERA-<version>.zip` readme. Source code is not published here.
